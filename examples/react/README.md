# React example

A Vite + React app using `@qikbar/qikbar/react`.

```bash
# from the repo root
bun install
bun run build:lib
cd examples/react && bun run dev
```

It shows `<Qikbar>` with routes, commands and extensions, client-side navigation through state, `useCommands` for page-specific commands, and `<QikbarTrigger>`.
